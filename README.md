# stage-door → house-lights

**This repository moved.** stage-door is one of the five skills of
[house-lights](https://github.com/ruinosus/house-lights) and is now called **gates-and-handoffs**. Install it from there:

```
/plugin marketplace add ruinosus/house-lights
/plugin install house-lights@house-lights
```

If you installed `stage-door` from this repository, remove it: `/plugin uninstall stage-door@stage-door`. Its files keep working
with the new skill. The gallery is now https://ruinosus.github.io/house-lights/gates-and-handoffs/; the npm command is
`npx house-lights gates-and-handoffs <file>`. This repository is archived and keeps its history and releases.
